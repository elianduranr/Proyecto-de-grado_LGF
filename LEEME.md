# Ejecución de Modelo 02

1. Instalar `numpy`, `pandas`, `pyarrow`, `matplotlib`, `seaborn`, `jupyter`, `nbformat` y `nbclient`.
2. Desde la raíz ejecutar `python scripts/construir_base_modelo02.py`.
3. Ejecutar `python scripts/validar_base_modelo02.py`.
4. Abrir `Notebooks/00_entendimiento del estimado.ipynb` y luego `Notebooks/02.ipynb`.

El constructor usa rutas relativas y funciona en Windows, Linux y macOS. Los datos fuente no se sobrescriben; solo se regeneran `Datos/modelado/` y `Datos/modelado/auditoria/`.

Antes de interpretar resultados, leer `CONTEXTO_PROYECTO.md`, `AUDITORIA_REVISION_MODELO02.md` y `DECISIONES_PENDIENTES_TUTOR.md`.
